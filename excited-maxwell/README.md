# Bee Task Roulette

A small static task organiser with a bee mascot. The button next to the Task Bar opens a roulette wheel containing the current tasks, picks one randomly, and makes the bee hold up the selected task for seven seconds while saying "good luck !".

## Run locally

```bash
npm run start
```

Then open <http://localhost:5173/excited-maxwell/> if serving from the repository root, or <http://localhost:5173/> if serving from this directory.

## Test

```bash
npm test
```
